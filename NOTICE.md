## Modifications in this repository
This repository adapts and extends ai-job-search:
1. Find / Apply / Reach workflow (`/find`, `/apply`, `/reach`).
2. Unified answer bank for consistent, single-source question answering.
3. Research notes generator for role summaries and company context.
4. Supervised Claude-in-Chrome application assistance with user confirmation before submit.
5. People finding with configurable daily caps and role-based discovery.
6. Outreach drafts with an automated validator and approval workflow.
7. Local web dashboard (`harness/dashboard.py`) for pipeline visibility and control.
8. Configurable target profile and strict PII guard protection for personal data.
